# Contrats

`kontexte.role/1` et `kontexte.mission/1` sont validés en Python sans dépendances.
Les schémas JSON Schema fournissent une validation supplémentaire et facilitent les outils d'édition.
Les fichiers dans `docs/ekole-orgo/annexes/schemas` sont conservés **historiquement**, leurs anciens formats `ekole.*-proposal` ne sont pas les contrats natifs de Kontexte.
Une validation technique ne remplace jamais la validation pédagogique ou la sécurité d'Orgo.
