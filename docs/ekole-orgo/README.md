# Documentation historique de l'upgrade Ekole–Orgo v1.1

Ces 19 fichiers reprennent la documentation d'upgrade demandée lors de la conception. Ils sont conservés pour la traçabilité et **ne sont pas les contrats exécutables de Kontexte**. Certaines pages anciennes proposent des responsabilités révisées. En cas d'écart, la décision canonique est `09_ADR_ORGO_GRAND_ORCHESTRATEUR.md`, puis `../decisions/ADR-001-ORGO-CANONIQUE.md` et les contrats dans `schemas/`.

Ne pas copier l'ensemble de ces documents en vrac dans le `site/` public d'Ekole : ils comprennent des annexes éditoriales et des exemples de validation, pas des pages pour enfants.
